## What I'm Working On

Three projects currently occupying most of my development attention:

<details>
<summary><strong>pyDoctor</strong> — Python Project Diagnostics & Repair</summary>

A CLI-first tool that examines Python projects, identifies common problems, and helps repair them.

- Project structure and configuration diagnostics.
- Import and runtime issue detection.
- Security checks for common mistakes.
- Automatic fixes for safe, well-understood issues.
- Approval before potentially disruptive repairs.
- Diagnostic reports and repair history.

**Stack:** Python 3.12+ · Typer · Rich · pytest

</details>

<details>
<summary><strong>DataLens</strong> — Java Data Analytics Workbench</summary>

A desktop application for exploring datasets, performing statistical analysis, and experimenting with machine learning.

Planned capabilities include data profiling, cleaning, descriptive statistics, hypothesis testing, regression, classification, clustering, and interactive visualizations.

An important part of this project is implementing selected statistical and machine-learning algorithms rather than relying entirely on external libraries.

**Stack:** Java 21+ · JavaFX · Gradle · SQLite

</details>

<details>
<summary><strong>Gauge</strong> — AI Usage Monitor</summary>

A browser extension designed to make AI provider usage easier to understand and track.

- Provider-specific usage monitoring.
- Quotas and reset-time information where available.
- Daily, weekly, and monthly usage history.
- Consumption statistics and trends.
- Notifications and provider-specific integrations.

The idea is to distinguish actual provider-reported information from estimates instead of presenting uncertain data as fact.

**Stack:** TypeScript · Manifest V3 · HTML · CSS

</details>

**Smart India Hackathon — Problem Statement Solution.**

`Python` `Ollama` `Linux`
